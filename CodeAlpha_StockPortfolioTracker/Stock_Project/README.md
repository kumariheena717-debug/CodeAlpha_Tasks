Domain:Python Programming Internship

Intern:Heena Kumari

Organization:CodeAlpha

Project Overview

This is a simple Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship. The program allows users to enter stock names and quantities, calculates the total investment value using predefined stock prices, and displays the portfolio summary.

Features

* User inputs stock names and quantities.
* Uses a hardcoded dictionary for stock prices.
* Calculates total investment value.
* Displays portfolio summary.
* Saves results to a text file.

Technologies Used

* Python
* Dictionaries
* Loops
* Input/Output
* File Handling

How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

python main.py
